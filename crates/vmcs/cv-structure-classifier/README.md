# cv-structure-classifier

Детерминированная классификация неструктурированного текста резюме в каноническую модель документа.

Вход: сырой текст, извлечённый из PDF, DOCX, TXT или OCR-скана.
Выход: структурированная модель резюме в форматах DockCV TOML и JSON Résumé, включающая выделенные контакты (имя, телефон, email, ссылки), секции с опытом работы, образованием, навыками, датами и буллетами, а также список неразмещённых строк (`unplaced`).

Капсула класса `atom`: чистая функция $y = f(x)$, без часов, генераторов случайных чисел, сети и хранилища.

## Принцип работы

1. Распознавание контактного блока по эвристикам и регулярным выражениям (email, телефон, URL, профили соцсетей).
2. Мультиязычная классификация заголовков секций (Work, Education, Skills, Certificates, Summary) на 11+ языках через таксономию `taxonomy.toml` и нечёткое сопоставление (расстояние Левенштейна).
3. Извлечение датированных сущностей (позиция, компания/учебное заведение, интервал дат, буллеты).
4. Сохранение нераспознанных строк в коллекцию `unplaced` без потери данных.
