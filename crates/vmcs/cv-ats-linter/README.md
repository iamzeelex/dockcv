# cv-ats-linter

Детерминированный аудит резюме на соответствие требованиям систем автоматического скрининга (ATS, Applicant Tracking Systems).

Вход: сериализованное резюме в формате JSON Résumé, DockCV TOML или AltaCV.
Выход: типизированный отчёт со списком обнаруженных проблем (неизвестные заголовки секций, повреждённые или инвертированные даты, отсутствие контактных данных, скрытые пробельные символы Unicode, нерендеримый Typst-маркап).

Капсула класса `atom`: чистая функция $y = f(x)$, без часов, генераторов случайных чисел, сети и хранилища.

## Проверяемые правила ATS

1. **HeadingNoParserKnows**: нестандартный заголовок секции, не распознаваемый парсерами (Taleo, Workday, Greenhouse).
2. **DateNoParserCanRead**: строка даты, не поддающаяся распознаванию.
3. **DatesRunBackwards**: дата окончания хронологически предшествует дате начала.
4. **NoWayToReachThePerson**: отсутствие как адреса электронной почты, так и номера телефона.
5. **MarkupThatNeverRenders**: нерендеримый Typst-маркап (например, `#strong[...]`), попадающий в текст сырой строкой.
6. **ListMarkerTypedIntoTheText**: дублированный маркер списка (буллеты `•`, `-`), набранный вручную в тексте элемента.
7. **CharactersNoFaceCanSet**: символы, отсутствующие в базовых шрифтовых гарнитурах.
8. **WhitespaceNobodySees**: невидимые пробельные символы (неразрывные пробелы, узкие пробелы, нулевая ширина), склеивающие слова в ATS.
